排砖宝 · 全系统功能审查与腾讯云部署验收清单 v1.5
用途：AI 代码审查、人工走查、上线前确认
原则：所有项必须通过，不通过不可发布。带 ★ 为 AI 极易遗漏的辅料和边界逻辑。

一、用户端功能完整性（三端一致）
1.1 户型输入
手绘拍照上传：移动端调用相机 / 相册，Web 端文件选择，桌面端系统对话框。

AI识别回填：手绘图上传后，后端返回预估多边形及数字尺寸，前端可编辑。

精准多边形编辑器：

顶点拖拽、添加/删除。

各边长度手动输入 (mm)。

自动吸附水平/垂直。

双边尺寸联动校正 (改一边，整体几何保持闭合且角度不变)。

预设户型模板 (矩形、L形) 可快速生成。

1.2 瓷砖排版配置
瓷砖规格输入 (长×宽 mm，留缝宽度)。

铺贴方向：横/竖/自定义角度。

起铺点交互：可拖拽十字准星，松手自动吸附墙角/中心，实时重算。

切割规则设定：最小砖比例、非整砖优先放置位置 (门口对侧/隐蔽处)。

1.3 精准排版计算与可视化
实时生成排版网格 (Konva 渲染)。

整砖与切割砖分区显示 (不同填充或线型)。

切割砖尺寸标注 (引线显示裁剪尺寸)。

起铺点符号和方向箭头标注。

1.4 ★ 主砖 + 配套辅料全量计算 (AI 最易漏)
瓷砖胶/粘结剂：输入基层类型系数，输出 kg/㎡ 及总重量。

美缝剂：根据砖尺寸+缝宽+面积计算支数 (含手工调整系数)。

水泥砂浆：若选传统方式，按配合比输出水泥(kg)、砂子(m³)。

找平器/十字卡：按砖数量推荐包数。

防水涂料/界面剂：若含厨卫阳台，可选计算。

其他辅料：填缝剂、阳角条、瓷砖背胶等可手动增选加项。

1.5 辅料清单展示
所有辅料与主砖在同一表格内列出：品名、规格、数量、单价、金额。

支持手动新增自定义辅料行。

1.6 材料价格与总造价
商家可为每种材料填入单价 (元/片或元/单位)。

显示开关：可一键隐藏单价/金额列 (给业主看时显示“商议”)。

总造价自动合计 (主砖+辅料总价)。

★ 免费用户无法填入价格，清单中价格列显示“会员功能”或隐藏。

二、用户确认单模块
2.1 内容结构 (5页)
封面：项目名称、面积、方案编号、日期；会员商家 Logo+名称，免费灰色占位。

铺贴效果图：真实纹理排版截图，含起铺点/方向标注。

材料明细与报价：完整主砖+辅料表格，按权限显示价格。

商家联系页：会员 Logo+电话+地址+二维码；免费大面积升级引导。

客户签字区：签字线、日期、备注。

2.2 多格式与跨端
HTML 在线预览：移动端/桌面浏览器可查看，卡片纵向布局，无横向滚动。

PDF 下载：版式稳定，手机阅读器打开正常。

PPT 下载：生成 .pptx，手机 WPS/Office 打开内容不错位。

分享功能：生成唯一链接，可发微信/邮件，支持免登录查看 (Token 鉴权)。

三、免费/会员权限体系
JWT 中携带 is_member 和 user_id。

前端根据会员状态条件渲染 (升级按钮、占位信息)。

后端二次校验：生成 PPT/PDF 时强制检查，免费用户不可包含真实商家信息。

免费水印：底部显示“由排砖宝生成”，不可关闭。

限制次数：免费用户每月导出或确认单份数限制 (可配置)。

四、后台管理中心 (Web 管理端)
门店信息编辑 (Logo, 名称, 电话, 地址, 二维码)。

产品库管理：添加产品、上传纹理、设置规格。

SKU 价格管理：砖规格关联单价。

订单列表：查看已生成确认单，状态流转 (预确认/已确认/生产)。

管理员可查看所有门店数据 (超管)。

八、★ 腾讯云部署环境验收
8.1 基础资源
云服务器 CVM (标准型 2核4G 以上)，操作系统 Ubuntu 22.04 或 CentOS 7.9。

已绑定公网 IP 并设置安全组 (开放 80/443/22 仅限白名单)。

域名已备案，解析至 CVM IP。

8.2 容器化与运行环境
安装 Docker & Docker Compose。

后端服务、数据库、Redis 均通过 compose 管理。

前端静态文件通过对象存储 (COS) + CDN 分发，或由后端 Nginx 代理。

8.3 数据库与存储
云数据库 PostgreSQL (或自建)，开启备份策略 (自动每日备份)。

开启 SSL 连接。

文件存储：使用腾讯云 COS 存储手绘图、纹理、生成的 PDF/PPT (设置生命周期，临时文件自动过期)。

COS 配置跨域 CORS 规则，允许前端域名。

8.4 SSL 与网络
申请免费 SSL 证书 (或使用腾讯云 SSL 服务)，配置到负载均衡或 Nginx。

所有 HTTP 流量强制跳转 HTTPS。

CDN (内容分发) 加速静态资源及用户生成文件下载。

API 接口启用 Gzip 压缩。

8.5 环境变量与密钥管理
.env 文件不提交代码库，生产使用服务器环境变量注入。

JWT_SECRET、数据库密码、OSS 密钥使用强随机值。

COS SecretId/Key 不以明文存于前端。

8.6 监控与备份
云监控告警：CPU > 80%，内存 > 80%，磁盘使用率 > 85% 短信通知。

应用日志接入 CLS (日志服务) 或通过 Docker 日志插件收集。

数据库每日自动备份，保留 7 天。

文件存储开启版本控制 (防误删)。

8.7 域名与CDN配置
前端域名：app.paizhuanbao.com 指向 COS/CDN 或 Nginx。

API 域名：api.paizhuanbao.com 指向后端服务器。

文件访问域名：static.paizhuanbao.com (CNAME 到 COS 域名)，避免跨域。

CDN 缓存策略：HTML 不缓存或短缓存，静态资源长期缓存。
